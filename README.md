# 차근차근 — 내 차랑 말하기

새 차에서 아직 안 써 본 기능을 하루 하나 골라 주고, 운전자가 직접 켰는지 **차 신호로 확인**해 주는 Pleos Connect 앱.
글레오(음성 비서)에게 하는 한 문장으로 배우고, 말로 하든 버튼으로 하든 차가 바뀐 것을 앱이 알아채 주차할 때 칭찬한다.

- 주행 중: 오늘의 말 말풍선 하나뿐인 정지 화면, 버튼·소리 없음. 앱은 차를 바꾸지 않고 읽기만 한다(차량 제어 권한 없음).
- 정차 중: 오늘의 문장 소개(음성 4종·말투 3종), 오늘의 버튼 그림("차가 보고 있어요" — 차가 켜짐을 확인하면 그림이 채워짐), 칭찬 카드에 "차가 확인한 것" 표시, 노선도 단어장(익힌 말 = 지나온 역; 말로 하기 14 · 손으로 익히기 4), 누적 주행거리 관리 소식.
- 내 차 꾸미기: 차가 확인했을 때만 포인트가 쌓이고(새로 익힌 기능 100P, 18개 완주 300P), 주차 중에 지붕 장식·차 색·창 안 소품을 단다. 첫 화면 노선 위에 작은 내 차가 선다. 연속 기록·순위·뽑기 없음.
- 내 차 이름(애칭)을 정하면 화면과 음성이 "OO랑 말하기"로 바뀐다.
- 화면: 17인치 가로, 내비 옆 반쪽 창, 작은 화면(비율 축소), 낮·밤 테마(글자 대비 4.5:1·그래픽 3:1 이상).
- 네트워크·계정 없음. 기록은 차 안에만 저장.

## 실행 방법
1. Pleos Connect Emulator v2.1.0 (Android API 34, Automotive)를 Cold boot로 실행
2. `adb install -r apk/첫시동_차근차근_release.apk`
3. 앱 목록에서 실행 (앱 아이콘: 말풍선 + 체크)

## 소스에서 빌드
- JDK 17, Android SDK 34, Gradle 8.9 (wrapper 포함)
- `cd android && ./gradlew :app:assembleDebug`
- 쓰는 SDK: Pleos Vehicle 2.3.2(읽기), TextToSpeech 3.3.1(ON_DEVICE), AAOS CarUxRestrictionsManager

## 테스트 환경 및 필요한 설정
- Virtual Console: `adb forward tcp:8088 tcp:8088` → http://127.0.0.1:8088/
- 기본 시나리오(약 1분)
  1. 기어 P에서 앱 실행 → 오늘의 문장 "앞 유리 김 서림 없애 줘"
  2. Virtual Console에서 기어 Drive → 주행 화면
  3. 앞 유리 제상(hvac-defroster, front) 켜기 → "차가 알아챘어요"
  4. 기어 Park → 칭찬 카드와 음성
- 명령으로 재현: `python3 tools/vc.py run tools/scenarios/demo_core.json`
- 차 화면의 공조 버튼으로 해 보기: 에뮬레이터에는 공조 장치가 없어 버튼을 눌러도 상태가 바뀌지 않는다. `python3 tools/car-echo.py`를 켜 두면 버튼 요청을 실제 상태로 반영한다(앱 코드와 무관한 시험 도구).
- 이미 켜져 있는 기능은 "새로 켠 것"이 아니라서 세지 않는다. 시작 전에 해당 기능을 꺼 두면 된다.
